# PRD — Nada's Birthday Website (عمار ❤️ ندى)

## Original Problem Statement
Build the complete final version of a romantic, interactive, mobile-only birthday website
from Ammar (عمار) to his girlfriend Nada (ندى, born 14 September 2006). Every text must read
as Ammar speaking directly to Nada in casual Arabic — never a narrator, AI, or third person.
Dark cinematic style (black, deep red, soft pink, warm white, subtle gold), stars, soft glows,
no photos, no stock images, no generic romantic filler, no Emergent branding, lightweight and
fast on phones, exportable and independently deployable.

## Architecture
- Frontend-only React app (CRA + craco + Tailwind). Backend untouched (template default).
- Single scroll journey gated behind an intro overlay ("ادخلي ❤️" starts music on first tap).
- `/app/frontend/src/App.js` — scene composition + music track switching via IntersectionObserver.
- Components: Intro, Starfield, FloatingHearts, Reveal (scroll reveals), HeartBurst, Quiz,
  Countdown (live + birthday state), Confetti (canvas), FinalScene (staged reveal).
- `src/hooks/useAudio.js` — crossfading audio manager, floating music toggle, SFX, graceful
  fallback if audio files are missing.
- `/app/frontend/public/audio/*.mp3` — self-composed placeholder tracks (intro, emotional,
  playful, celebration, finale + pop/wrong SFX), generated by `/app/scripts/generate_audio.py`
  (numpy + ffmpeg). Replaceable later with real music, same filenames.
- Hidden test hook: `?date=2026-09-14` URL param previews the birthday-day state.

## User Personas
- Nada — the only reader; opens the link on her phone (iPhone/Android, portrait).
- Ammar — the author; may replace the mp3 files later and deploy the build himself.

## Core Requirements (static)
1. Intro scene: staged reveal "ندوشتيي…" → "اليوم انولدت حياتي ونور عيونيي…" → "اليوم يوم وحدة
   أحبها بشكل ما أعرف أوصفه بالكلام." → "ادخلي ❤️" (starts music + heart burst).
2. Birthday scene: 14 سبتمبر 2006 with Ammar-voice lines.
3. Message scene: the exact personal message, revealed gradually on scroll.
4. Rigged quiz ("عمار يختبر ندى 😂"): 3 questions, every answer wrong → shake + "غلط" animation
   + "الإجابة الصحيحة 😌:" with the exact funny answers + haptics + SFX.
5. New-year scene: "كبرتي سنة يا عجوزتي 😂❤️" + live countdown to Sep 14 2026; on the day →
   "اليوم يوم ندى ❤️🎂" + confetti.
6. Final scene: staged quiet reveal of the exact final message → "Happy Birthday, Nada ❤️" →
   "14 September 2026" → "من عمار ❤️" → "أحبك."
7. Music per scene with fade out/in, floating 🎵 toggle, no autoplay dependency.
8. Mobile-only: no horizontal scroll, safe areas, touch-friendly, lightweight.

## Implemented (2026-09-11)
- All 6 scenes with exact specified Arabic texts and staged/scroll reveals.
- Full rigged quiz flow with wrong-answer animation + correct-answer reveal + haptics.
- Live countdown (verified real ticking values) + birthday-day celebration state with confetti.
- 7 self-composed placeholder audio tracks with crossfade; floating music on/off button.
- White-label: removed all Emergent references from HTML/src; production build verified clean.
- Verified: full e2e flow at 390x844 and 360x640, no horizontal overflow, no console errors.
